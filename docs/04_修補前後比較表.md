# 04 修補前後比較表

本表提供學員與教師作為安全改善成果的比對模板。您可以利用本表記錄在弱點版網站（Port 8080）中發現的漏洞、修補方式，以及在修正版網站（Port 8081）重新掃描驗證後的結果。

| **07** | 報名超額併發超賣 | A06:2025 Insecure Design | 🟡 Medium | 否 | **手動**: 使用 ZAP Thread 併發發送 10 次報名，餘額不足依然成功。 | 使用資料庫 Transaction 與 `SELECT ... FOR UPDATE` 行鎖防止併發。 | **手動**: 餘額不足會被事務阻擋並回滾。 | 是 | 需高併發測試。 |

## 📝 學員實作紀錄指引

1. **檢測記錄**：學員於「弱點版網站 (localhost:8080)」發現漏洞時，應記錄其危害（如：能下載資料庫密碼，屬於 A05:2025 SQL 注入，高風險）。
2. **修補代碼**：參考安全修正版（localhost:8081）代碼，並在弱點版程式碼中進行修復（或直接對照兩者差異）。
3. **驗證防護**：修補後再次使用 ZAP 掃描或手動測試，確保該漏洞在修補前後比較中「已完全消除」，且「不影響原有的業務功能」。
