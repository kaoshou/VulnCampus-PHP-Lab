## 3. 修補措施與成效驗證

### 1. SQL Injection 漏洞
- **修補措施**：全面改用 PDO Prepared Statements。
- **ZAP 複掃結果**：🔴 **警報消除**。發送注入符號時，系統僅將其視為純文字進行課程查詢，無任何資料庫溢出或語法錯誤。

### 2. Cross Site Scripting (Stored & Reflected)
- **修補措施**：前端與後端輸出改用 `htmlspecialchars($val, ENT_QUOTES, 'UTF-8')` 對字元 `<` 與 `>` 進行轉義。
- **ZAP 複掃結果**：🟡 **警報消除**。注入的 `<script>` 標籤以字串形式安全呈現，無法被瀏覽器執行。

### 3. Path Traversal & 越權下載
- **修補措施**：改用檔案 ID (file_id) 進行資料庫查表下載，完全移除 URL 的實體檔案路徑。
- **ZAP 複掃結果**：🔴 **警報消除**。無法再藉由 `../` 下載敏感檔案。

### 4. 任意檔案上傳 Webshell
- **修補措施**：限制副檔名 (僅限圖片)、利用 `finfo` 檢測真實 MIME、上傳檔名亂數化、在 `uploads/` 配置 `.htaccess` 阻擋 PHP 腳本解析。
- **ZAP 複掃結果**：🔴 **警報消除**。上傳 php 檔案被阻擋；直接訪問上傳目錄下的 PHP 被 Apache 拒絕 (403 Forbidden)。

### 5. 命令注入 (RCE)
- **修補措施**：使用 `filter_var()` 嚴格檢查輸入必須為 IP/Hostname 格式，並用 `escapeshellarg()` 跳脫引數。
- **ZAP 複掃結果**：🔴 **警報消除**。輸入特殊符號直接提示格式錯誤。

---

## 4. 結論

安全修正版（Port 8081）網站的安全程度已有顯著提升。OWASP ZAP 掃描報告中的高風險及中風險漏洞已**全部消除**。
殘留之低風險警報主要為「未啟用 HTTPS 加密傳輸」，此項目在本機教學環境中屬於可接受風險，若要部署於網際網路，必須配置 SSL 憑證以防範傳輸攔截。
